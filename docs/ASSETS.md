# Asset manifest

Every third-party or non-code asset in the repo, with source and licence.
Notices the licences require are in `/THIRD_PARTY_NOTICES.md`; people to credit
are in `/CREDITS.md`. Last checked 12 Nov 2026 (branch lane/p0-paperwork).

Status values: OK (source and licence read and recorded), NOTICE NEEDED (licence
requires an attribution or notice; supplied in THIRD_PARTY_NOTICES.md), NEEDS SOURCE (no origin recorded),
TO BE REPLACED (owner has decided to swap it out).

"Verified" below means I read it in the file or on the upstream page named. Anything
else is marked not verified.

## How to add a row

1. The row goes into this file BEFORE the asset enters the project: files, what, source URL, author, licence, date, where used, status.
2. Read the licence on the source page and say in the row what you read. If you did not read it, write "not verified".
3. Raw sources (.glb, .png, .wav, fonts) live in git-ignored `assets_src/`, never in git. Only the import products are committed (see `docs/ASSET_PIPELINE.md`).
4. If the licence requires attribution (CC BY and similar), also add it to `CREDITS.md`, to `THIRD_PARTY_NOTICES.md` where a notice text is required, and note it for the in-game credits screen.
